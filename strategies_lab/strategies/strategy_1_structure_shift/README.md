# Стратегия 1: Market Structure Shift (MSS / CHoCH)

## Описание:
Вход осуществляется только после подтверждения смены тренда на микроструктуре подволны 4-5.

## Логика:
1. Алгоритм находит локальный ключевой свинг подволны 4:
   - Для SHORT: минимум (Swing Low) перед вершиной W5.
   - Для LONG: максимум (Swing High) перед впадиной W5.
2. Триггер: закрытие последующей свечи за уровнем свинга (пробой структуры).
3. Инвалидация: если цена обновляет W5 до пробоя свинга — сигнал отменяется, спасая от удлинения волны и стоп-лосса.
4. Стоп-лосс: ставится с минимальным запасом (+0.15%), что даёт высокий R:R.
