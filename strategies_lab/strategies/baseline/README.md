# Стратегия 0: Baseline (Эталон RalphTradeBot v2.2)

## Описание:
Текущая модель бота:
- Вход: немедленный на закрытии свечи экстремума W5.
- Стоп-лосс: за экстремумом W5 (+0.3% буфер).
- Тейк-профиты: Фибоначчи 23.6%, 38.2%, 50.0%, 61.8% (доли 25%, 35%, 25%, 15%).
- Безубыток: перенос SL во вход +0.1% после взятия TP2.

Служит эталоном (benchmark) для оценки эффективности фильтров других стратегий.
