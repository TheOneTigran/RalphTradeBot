# Стратегия 4: Chandelier Volatility Trailing (Динамическое сопровождение)

## Описание:
Сочетание надежного входа по свечному поглощению и динамического удержания прибыли по волатильному скользящему стопу Chandelier Exit (2.5 * ATR 14).

## Логика:
1. Вход: по подтверждению Absorption Bar.
2. Фиксация: 30% на TP1 (23.6% Фибо), 30% на TP2 (38.2% Фибо) с переносом стопа в безубыток (+0.1%).
3. Трейлинг: оставшиеся 40% позиции не сбрасываются по фиксированной цели 61.8%, а сопровождаются по формуле:
   - SHORT: Trail_SL = min(Trail_SL, Low + 2.5 * ATR)
   - LONG: Trail_SL = max(Trail_SL, High - 2.5 * ATR)
4. Позволяет забирать глобальные развороты тренда на 100%+ длины импульса.
