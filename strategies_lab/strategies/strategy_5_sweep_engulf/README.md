# Стратегия 5: Свечной свип-поглощение (Sweep & Engulfing) + 50% Retracement Limit

## 🎯 Концепция стратегии:
Тестирование авторской гипотезы контртрендового входа на пике 5-й волны Эллиотта:
1. **Импульс + Дивергенция**: нахождение математически верифицированного 5-волнового импульса W0-W5 с подтверждённой RSI-дивергенцией между W3 и W5.
2. **Свечной свип экстремума (Liquidity Sweep)**:
   - В пределах 1–3 свечей после W5 экстремальная точка пробивается тенью (High для шорта, Low для лонга).
3. **Поглощение тела (Body Engulfing)**:
   - Свеча свипа (свеча S) закрывается в противоположную сторону и полностью перекрывает тело экстремальной свечи W5 (для шорта закрытие ниже тела W5, для лонга — выше тела W5).
4. **Вход по лимитному ордеру на 50% диапазона**:
   - Вход строго лимитным ордером на уровне 50% полного диапазона (High - Low) свечи поглощения S:
     `Limit Price = Low(S) + 0.5 * (High(S) - Low(S))`
   - Ожидание заполнения в течение `N` свечей (исследуются окна 1, 2, 3, 5 свечей).
5. **Стоп-лосс**:
   - Строго по кончику тени свечи поглощения S (без буфера):
     - SHORT: `SL = High(S)`
     - LONG: `SL = Low(S)`
6. **Тейк-профит**:
   - Фиксированный 1:3 R:R:
     - SHORT: `TP = Limit - 3 * (SL - Limit)`
     - LONG: `TP = Limit + 3 * (Limit - SL)`
7. **Комиссии биржи**:
   - Фиксированные 0.05% на вход + 0.05% на выход (суммарно 0.10% от оборота).
