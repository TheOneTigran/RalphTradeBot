# Стратегия 3: Statistical Volatility Re-entry (Кельтнер / ATR)

## Описание:
Вход при возврате цены внутрь канала волатильности (EMA 20 ± 2.0*ATR 14).

## Логика:
1. Волна 5 образует выброс за пределы нормального распределения волатильности (выше верхней или ниже нижней полосы).
2. Триггер: закрытие свечи возвращается обратно внутрь канала (Close < Upper для SHORT, Close > Lower для LONG), подтверждая затухание моментума.
3. Стоп-лосс: за экстремумом W5.
