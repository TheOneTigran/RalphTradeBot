# 🧪 RalphTradeBot — Strategies Research Lab

Модульная лаборатория для строгого математического тестирования и сравнения торговых стратегий импульсов Эллиотта.

## 🎯 Архитектурный принцип:
- **100% изоляция от продакшена:** ни один рабочий файл бота (`live_scanner.py`, `analytics_db.py`, `telegram_notifier.py` и т.д.) не зависит от этой папки.
- **Единый пул данных:** все стратегии тестируются на одних и тех же исторических свечах (из `data/*.parquet`) и на одном пуле подтверждённых импульсов Эллиотта.
- **Индивидуальная папка на стратегию:** результаты (`results/metrics.json`, `results/trades.csv`, `results/summary.md`) сохраняются строго внутри папки стратегии.
- **Легкая очистка:** любую неподошедшую стратегию можно удалить в одну команду, не затронув остальной проект.

## 📁 Структура лаборатории:
```text
strategies_lab/
├── engine.py                     # Универсальный бектест-движок (загрузка, ресемплинг, метрики)
├── run_lab.py                    # Главный запуск и построение сравнительной таблицы
├── COMPARISON_REPORT.md          # Итоговый сравнительный лидерборд
└── strategies/
    ├── base_strategy.py          # Базовый интерфейс
    ├── baseline/                 # Базовый вариант бота (вход на W5, 4 ТП Фибо, БУ после ТП2)
    ├── strategy_1_structure_shift/     # Стратегия 1: Слом локальной структуры (MSS / CHoCH)
    ├── strategy_2_absorption_bar/      # Стратегия 2: Свечное поглощение (Outside Bar / Pinbar)
    ├── strategy_3_keltner_reentry/     # Стратегия 3: Статистический возврат Keltner/ATR
    └── strategy_4_chandelier_trailing/ # Стратегия 4: Динамический волатильный трейлинг Chandelier
```

## 🚀 Как запускать:

### 1. Запуск полного сравнительного аудита всех стратегий:
```bash
python strategies_lab/run_lab.py
```

### 2. Запуск на конкретном таймфрейме (например, 15m или 1h):
```bash
python strategies_lab/run_lab.py --interval 15m
```

### 3. Запуск отдельной конкретной стратегии:
```bash
python strategies_lab/run_lab.py --strategy 1
```

## 🧹 Как очистить/удалить ненужные стратегии:
После выбора победителя любую ненужную папку можно просто удалить:
```powershell
Remove-Item -Recurse strategies_lab/strategies/strategy_3_keltner_reentry
```
