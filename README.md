# 🤖 RalphTradeBot — Autonomous Elliott Wave & RSI Divergence Trading Bot

**RalphTradeBot** — автономная торговая система и аналитический движок, объединяющий математический детектор 5-волновых импульсов Эллиотта v2.1 и мультимодальный аудит нейросетью Vision AI.

---

## 🌟 Ключевые возможности

1. **Математическая верификация импульса v2.1**:
   - **Строгие правила Эллиотта**: Волна 2 никогда не уходит за начало Волны 1; Волна 3 никогда не является кратчайшей; абсолютный запрет перекрытия Волны 4 и Волны 1 (`Overlap W4/W1 = 0`).
   - **Истощение W0 (RSI Exhaustion)**: Импульс обязан зарождаться в фазе истощения ($RSI \le 32$ для бычьего, $RSI \ge 68$ для медвежьего) либо глубокого охлаждения. Зарождение в боковике ($RSI \in [48, 52]$) штрафуется как `CHOP`.
   - **Предваряющая дивергенция W0 (Origin Divergence)**: Детектирует разворотную дивергенцию перед стартом импульса и рисует аквамариновую линию `W0-DIV`.
   - **Закон моментума W3 (Momentum Peak)**: Волна 3 обязана иметь максимальный моментум на индикаторе RSI.

2. **Мультимодальный аудит Vision AI**:
   - Наносит волны $0 \dots 5$, уровни sweep и линии дивергенций `W0-DIV` и `DIV` прямо на свечной график TradingView.
   - Нейросеть (OpenRouter / Gemini Direct / Groq) визуально оценивает органичность тренда и возвращает вердикт на русском языке.

## 🚀 Быстрый запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Бэктест по основным пресетам с генерацией HTML-отчета
python backtest_runner.py

# Бэктест по всем 15 монетам
python backtest_runner.py --top15

# Бэктест с живой отправкой подтвержденных сигналов в Telegram
python backtest_runner.py --preset BTCUSDT_5m,ETHUSDT_15m --send-tg
```
